# cfp-watch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A weekly GitHub Actions job that finds open special-issue calls for papers for 12 management journals via Claude web search, keeps `data/calls.json`, publishes `docs/index.html` on GitHub Pages, and emails a digest only when something is new, changed, or errored.

**Architecture:** A small Python package `cfpwatch` with one module per responsibility: `fetch` (opportunistic direct page fetch with bot-page detection), `search` (one Claude `parse()` call per journal with the `web_search` server tool and a Pydantic output schema), `store` (JSON store + merge/delta logic), `render` (dashboard + email HTML), `notify` (Gmail SMTP), `cli` (orchestration). Every module takes and returns plain dataclasses so it is unit-testable without network.

**Tech Stack:** Python 3.12, `anthropic` >= 1.6, `pydantic` 2, `pyyaml`, `rapidfuzz`, `pytest`; stdlib `urllib`, `smtplib`, `html`, `json`. GitHub Actions + GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-17-cfp-watch-design.md`

`src/cfpwatch/models.py`:

```python
from __future__ import annotations

import datetime as dt
import hashlib
import re
from dataclasses import asdict, dataclass, field

_PREFIX = re.compile(
    r"^(call for papers|cfp|special issue|special research forum|special section|thematic issue)"
    r"\s*(on|:|-|–|—)?\s*",
    re.I,
)


def normalize_title(title: str) -> str:
    t = title.strip().lower()
    t = _PREFIX.sub("", t)
    t = _PREFIX.sub("", t)  # handle "call for papers - special issue on X"
    t = re.sub(r"[^\w\s]", " ", t)
    return re.sub(r"\s+", " ", t).strip()


def call_id(journal_key: str, title: str) -> str:
    digest = hashlib.sha1(normalize_title(title).encode()).hexdigest()[:8]
    return f"{journal_key}:{digest}"


def parse_date(s: str | None) -> dt.date | None:
    if not s:
        return None
    try:
        return dt.date.fromisoformat(s[:10])
    except ValueError:
        return None


@dataclass
class Journal:
    key: str
    name: str
    aliases: list[str] = field(default_factory=list)
    publisher: str = ""
    direct_urls: list[str] = field(default_factory=list)
    search_hints: list[str] = field(default_factory=list)


@dataclass
class Call:
    journal: str
    title: str
    guest_editors: list[str]
    opens: str | None
    deadline: str | None
    deadline_text: str | None
    url: str
    source_url: str
    summary: str
    confidence: str
    first_seen: str
    last_seen: str
    status: str = "open"
    misses: int = 0

    @property
    def id(self) -> str:
        return call_id(self.journal, self.title)

    def to_dict(self) -> dict:
        d = asdict(self)
        d["id"] = self.id
        return d

    @classmethod
    def from_dict(cls, d: dict) -> "Call":
        d = {k: v for k, v in d.items() if k != "id"}
        return cls(**d)


@dataclass
class JournalStatus:
    last_run: str | None = None
    last_ok: str | None = None
    last_error: str | None = None


@dataclass
class Delta:
    new: list[Call]
    changed: list[tuple[Call, str | None]]  # (call, previous deadline)
    expired: list[Call]
    errors: dict[str, str]

    @property
    def should_email(self) -> bool:
        return bool(self.new or self.changed or self.errors)
```

`src/cfpwatch/fetch.py`:

```python
from __future__ import annotations

import html as htmllib
import re
import urllib.error
import urllib.request
from urllib.request import urlopen  # module-level so tests can monkeypatch

USER_AGENT = (
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
    "(KHTML, like Gecko) Chrome/128.0 Safari/537.36"
)

_BLOCK_MARKERS = (
    "just a moment",
    "performing security verification",
    "are you a robot",
    "client challenge",
    "access denied",
    "verify you are human",
    "enable javascript and cookies to continue",
)

_SCRIPT_STYLE = re.compile(r"<(script|style|noscript)[^>]*>.*?</\1>", re.S | re.I)
_TAGS = re.compile(r"<[^>]+>")


def looks_blocked(text: str) -> bool:
    head = text[:20000].lower()
    return any(m in head for m in _BLOCK_MARKERS)


def html_to_text(html: str) -> str:
    text = _SCRIPT_STYLE.sub(" ", html)
    text = _TAGS.sub(" ", text)
    text = htmllib.unescape(text)
    return re.sub(r"\s+", " ", text).strip()


def fetch_text(url: str, timeout: float = 20.0, max_chars: int = 30000) -> str | None:
    req = urllib.request.Request(url, headers={"User-Agent": USER_AGENT, "Accept-Language": "en"})
    try:
        with urlopen(req, timeout=timeout) as resp:
            if getattr(resp, "status", 200) != 200:
                return None
            raw = resp.read()
    except (urllib.error.HTTPError, urllib.error.URLError, TimeoutError, OSError):
        return None
    body = raw.decode("utf-8", errors="ignore")
    if looks_blocked(body):
        return None
    return html_to_text(body)[:max_chars]
```

```python
from __future__ import annotations

import datetime as dt
import json
from dataclasses import asdict, dataclass, field
from pathlib import Path

from rapidfuzz import fuzz

from .models import Call, Delta, JournalStatus, normalize_title, parse_date

STALE_AFTER = 3
FUZZY_THRESHOLD = 90


@dataclass
class Store:
    calls: dict[str, Call] = field(default_factory=dict)
    journals: dict[str, JournalStatus] = field(default_factory=dict)

    @classmethod
    def load(cls, path: Path) -> "Store":
        if not path.exists():
            return cls()
        data = json.loads(path.read_text(encoding="utf-8"))
        calls = {c["id"]: Call.from_dict(c) for c in data.get("calls", [])}
        journals = {k: JournalStatus(**v) for k, v in data.get("journals", {}).items()}
        return cls(calls=calls, journals=journals)

    def save(self, path: Path) -> None:
        path.parent.mkdir(parents=True, exist_ok=True)
        data = {
            "calls": [c.to_dict() for c in sorted(self.calls.values(), key=lambda c: c.id)],
            "journals": {k: asdict(v) for k, v in sorted(self.journals.items())},
        }
        path.write_text(json.dumps(data, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")

    def open_calls(self, today: dt.date) -> list[Call]:
        def key(c: Call):
            d = parse_date(c.deadline)
            return (d is None, d or dt.date.max, c.journal, c.title)

        return sorted((c for c in self.calls.values() if c.status == "open"), key=key)


def _match_existing(store: Store, journal_key: str, found: Call) -> Call | None:
    if found.id in store.calls:
        return store.calls[found.id]
    norm = normalize_title(found.title)
    best, best_score = None, 0
    for c in store.calls.values():
        if c.journal != journal_key:
            continue
        score = fuzz.token_set_ratio(norm, normalize_title(c.title))
        if score > best_score:
            best, best_score = c, score
    return best if best_score >= FUZZY_THRESHOLD else None


def merge(store: Store, journal_key: str, found: list[Call], today: dt.date) -> Delta:
    delta = Delta(new=[], changed=[], expired=[], errors={})
    seen_ids: set[str] = set()
    ts = today.isoformat()

    for f in found:
        existing = _match_existing(store, journal_key, f)
        if existing is None:
            f.journal = journal_key
            f.first_seen = ts
            f.last_seen = ts
            f.status = "open"
            f.misses = 0
            store.calls[f.id] = f
            delta.new.append(f)
            seen_ids.add(f.id)
            continue
        old_deadline = existing.deadline
        if f.deadline and f.deadline != existing.deadline:
            existing.deadline = f.deadline
            delta.changed.append((existing, old_deadline))
        for attr in ("guest_editors", "opens", "deadline_text", "url", "source_url", "summary", "confidence"):
            val = getattr(f, attr)
            if val:
                setattr(existing, attr, val)
        existing.last_seen = ts
        existing.misses = 0
        if existing.status == "stale":
            existing.status = "open"
        seen_ids.add(existing.id)

    for c in store.calls.values():
        if c.journal != journal_key or c.status != "open":
            continue
        if c.id not in seen_ids:
            c.misses += 1
        d = parse_date(c.deadline)
        if d is not None and d < today:
            c.status = "expired"
            delta.expired.append(c)
        elif d is None and c.misses >= STALE_AFTER:
            c.status = "stale"

    st = store.journals.setdefault(journal_key, JournalStatus())
    st.last_run = ts
    st.last_ok = ts
    st.last_error = None
    return delta


def record_error(store: Store, journal_key: str, error: str, today: dt.date) -> None:
    st = store.journals.setdefault(journal_key, JournalStatus())
    st.last_run = today.isoformat()
    st.last_error = error[:500]
```

```python
from __future__ import annotations

import datetime as dt
from dataclasses import dataclass, field
from typing import Literal

import anthropic
from pydantic import BaseModel

from .models import Call, Journal, parse_date

DEFAULT_MODEL = "claude-sonnet-5"
FALLBACK_BETA = "server-side-fallback-2026-07-01"
MAX_PAUSE_RESTARTS = 3

WEB_SEARCH_TOOL = {"type": "web_search_20260209", "name": "web_search", "max_uses": 5}
WEB_FETCH_TOOL = {"type": "web_fetch_20260209", "name": "web_fetch", "max_uses": 3}


class FoundCall(BaseModel):
    title: str
    guest_editors: list[str]
    opens: str | None
    deadline: str | None
    deadline_text: str | None
    url: str
    source_url: str
    summary: str
    confidence: Literal["high", "medium", "low"]


class SearchOutput(BaseModel):
    calls: list[FoundCall]
    notes: str


@dataclass
class SearchResult:
    calls: list[Call] = field(default_factory=list)
    notes: str = ""
    input_tokens: int = 0
    output_tokens: int = 0
    error: str | None = None


def build_prompt(journal: Journal, today: dt.date, evidence: list[str]) -> tuple[str, str]:
    aliases = ", ".join(journal.aliases) or "none"
    hints = "\n".join(f"- {h}" for h in journal.search_hints) or "- (none)"
    system = f"""You are a research assistant who tracks special-issue calls for papers (CFPs) in management journals.
Today's date is {today.isoformat()}.

Target journal: {journal.name} (publisher: {journal.publisher}). Aliases: {aliases}.

What counts as a call:
- A special issue, special research forum, special section, thematic issue, or curated collection of THIS journal that is currently accepting submissions or has announced a future submission window.
- Exclude: conference calls, calls for other journals with similar names, regular-issue submission guidance, workshops, and calls whose final submission deadline is before today.

How to work:
- Use web_search. Prefer the publisher's or sponsoring society's pages. Useful query terms:
{hints}
- Try at least two different queries (for example: "{journal.name}" "special issue" call for papers; "{journal.name}" "call for papers" 2026 2027).
- Use web_fetch only on a promising result that is a publisher, society, or PDF page; if a fetch fails or returns a bot-check page, ignore it and rely on search snippets.
- Report a date only when a source states it. Use ISO YYYY-MM-DD. If the source gives only a vague date ("Spring 2027"), leave `deadline` null and put the phrase in `deadline_text`.
- `url` is the best page for the call itself; `source_url` is where you saw the information (may be the same).
- `confidence` is high when a publisher/society page confirms the call, medium for a credible secondary source, low for a single indirect mention.
- Put anything you could not verify, and any blocked sources, in `notes`. Return an empty `calls` list if there are none."""

    user = (
        f"Find all currently open or announced special issue calls for papers for {journal.name}. "
        "Include calls whose submission window opens in the future. Exclude calls whose deadline has passed."
    )
    if evidence:
        joined = "\n\n---\n\n".join(evidence)
        user += f"\n\nEvidence fetched directly from journal-related pages (may be partial):\n\n{joined}"
    return system, user


def _to_call(fc: FoundCall, journal: Journal, today: dt.date) -> Call | None:
    title = fc.title.strip()
    if not title:
        return None
    d = parse_date(fc.deadline)
    if d is not None and d < today:
        return None
    ts = today.isoformat()
    return Call(
        journal=journal.key,
        title=title,
        guest_editors=[g.strip() for g in fc.guest_editors if g.strip()],
        opens=fc.opens,
        deadline=d.isoformat() if d else None,
        deadline_text=fc.deadline_text,
        url=fc.url,
        source_url=fc.source_url,
        summary=fc.summary.strip(),
        confidence=fc.confidence,
        first_seen=ts,
        last_seen=ts,
    )


def find_calls(
    client,
    journal: Journal,
    today: dt.date,
    evidence: list[str],
    model: str = DEFAULT_MODEL,
    max_searches: int = 5,
) -> SearchResult:
    system, user = build_prompt(journal, today, evidence)
    messages: list[dict] = [{"role": "user", "content": user}]
    tools = [dict(WEB_SEARCH_TOOL, max_uses=max_searches), dict(WEB_FETCH_TOOL)]
    result = SearchResult()

    try:
        for _ in range(MAX_PAUSE_RESTARTS + 1):
            resp = client.beta.messages.parse(
                model=model,
                max_tokens=16000,
                system=system,
                messages=messages,
                tools=tools,
                thinking={"type": "adaptive"},
                output_format=SearchOutput,
                betas=[FALLBACK_BETA],
                fallbacks="default",
            )
            result.input_tokens += getattr(resp.usage, "input_tokens", 0) or 0
            result.output_tokens += getattr(resp.usage, "output_tokens", 0) or 0
            if resp.stop_reason == "pause_turn":
                messages = messages + [{"role": "assistant", "content": resp.content}]
                continue
            if resp.stop_reason == "refusal":
                result.error = "refusal: model declined the request"
                return result
            parsed: SearchOutput | None = resp.parsed_output
            if parsed is None:
                result.error = f"no structured output (stop_reason={resp.stop_reason})"
                return result
            result.notes = parsed.notes
            result.calls = [c for c in (_to_call(fc, journal, today) for fc in parsed.calls) if c]
            return result
        result.error = "pause_turn: exceeded restart limit"
        return result
    except anthropic.RateLimitError as e:
        result.error = f"rate limited: {e}"
    except anthropic.APIStatusError as e:
        result.error = f"api error {e.status_code}: {getattr(e, 'message', e)}"
    except anthropic.APIConnectionError as e:
        result.error = f"connection error: {e}"
    except anthropic.APIError as e:
        result.error = f"api error: {e}"
    return result
```

```python
th{font-weight:600;color:var(--muted);font-size:.85rem}.muted{color:var(--muted)}.badge{background:var(--new);color:#fff;border-radius:4px;padding:0 6px;font-size:.75rem}
.err{color:var(--warn)}details summary{cursor:pointer;color:var(--muted)}.wrap{overflow-x:auto}
"""


@dataclass
class RunMeta:
    today: dt.date
    model: str
    dashboard_url: str
    journals: list[Journal]


def _jname(meta: RunMeta, key: str) -> str:
    return next((j.name for j in meta.journals if j.key == key), key)


def _abbrev(meta: RunMeta, key: str) -> str:
    j = next((j for j in meta.journals if j.key == key), None)
    return (j.aliases[0] if j and j.aliases else key.upper())


def _deadline_cell(c: Call) -> str:
    if c.deadline:
        return escape(c.deadline)
    return escape(c.deadline_text or "—")


def _row(c: Call, meta: RunMeta, new_ids: set[str]) -> str:
    badge = ' <span class="badge">new</span>' if c.id in new_ids else ""
    eds = escape(", ".join(c.guest_editors)) or "—"
    return (
        f"<tr><td>{escape(_abbrev(meta, c.journal))}</td>"
        f'<td><a href="{escape(c.url, quote=True)}">{escape(c.title)}</a>{badge}'
        f'<div class="muted">{escape(c.summary)}</div></td>'
        f"<td>{_deadline_cell(c)}</td><td>{eds}</td><td>{escape(c.confidence)}</td></tr>"
    )


def _table(calls: list[Call], meta: RunMeta, new_ids: set[str]) -> str:
    if not calls:
        return '<p class="muted">No open calls.</p>'
    rows = "".join(_row(c, meta, new_ids) for c in calls)
    return (
        '<div class="wrap"><table><thead><tr><th>Journal</th><th>Call</th><th>Deadline</th>'
        f"<th>Guest editors</th><th>Conf.</th></tr></thead><tbody>{rows}</tbody></table></div>"
    )


def _status_table(store: Store, meta: RunMeta) -> str:
    rows = []
    for j in meta.journals:
        st = store.journals.get(j.key)
        n_open = sum(1 for c in store.calls.values() if c.journal == j.key and c.status == "open")
        ok = escape(st.last_ok) if st and st.last_ok else "never"
        err = f'<span class="err">{escape(st.last_error)}</span>' if st and st.last_error else ""
        rows.append(f"<tr><td>{escape(j.name)}</td><td>{n_open}</td><td>{ok}</td><td>{err}</td></tr>")
    return (
        '<div class="wrap"><table><thead><tr><th>Journal</th><th>Open</th><th>Last successful check</th>'
        f"<th>Last error</th></tr></thead><tbody>{''.join(rows)}</tbody></table></div>"
    )


def render_dashboard(store: Store, delta: Delta, meta: RunMeta) -> str:
    new_ids = {c.id for c in delta.new}
    open_calls = store.open_calls(meta.today)
    expired = sorted((c for c in store.calls.values() if c.status == "expired"),
                     key=lambda c: c.deadline or "", reverse=True)
    new_section = _table(delta.new, meta, new_ids) if delta.new else '<p class="muted">Nothing new this run.</p>'
    exp_rows = "".join(
        f"<tr><td>{escape(_abbrev(meta, c.journal))}</td><td>{escape(c.title)}</td><td>{_deadline_cell(c)}</td></tr>"
        for c in expired
    )
    return f"""<!doctype html>
<html lang="en"><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1">
<title>cfp-watch</title><style>{_CSS}</style></head>
<body>
<h1>Special-issue calls for papers</h1>
<p class="muted">Last run {escape(meta.today.isoformat())} · model {escape(meta.model)} · {len(open_calls)} open calls</p>
<h2>New this run</h2>
{new_section}
<h2>All open calls</h2>
{_table(open_calls, meta, new_ids)}
<h2>Journal status</h2>
{_status_table(store, meta)}
<details><summary>Expired calls ({len(expired)})</summary><div class="wrap"><table><tbody>{exp_rows}</tbody></table></div></details>
</body></html>
"""


def _email_list(calls: list[Call], meta: RunMeta, extra=None) -> str:
    items = []
    for c in calls:
        line = (f'<li><b>{escape(_abbrev(meta, c.journal))}</b> · <a href="{escape(c.url, quote=True)}">{escape(c.title)}</a>'
                f" · deadline {_deadline_cell(c)}")
        if extra:
            line += f" {extra(c)}"
        if c.summary:
            line += f'<br><span style="color:#666">{escape(c.summary)}</span>'
        items.append(line + "</li>")
    return "<ul>" + "".join(items) + "</ul>"


def render_email(store: Store, delta: Delta, meta: RunMeta) -> tuple[str, str]:
    parts = []
    if delta.new:
        js = sorted({_abbrev(meta, c.journal) for c in delta.new})
        parts.append(f"{len(delta.new)} new call{'s' if len(delta.new) != 1 else ''} ({', '.join(js)})")
    if delta.changed:
        parts.append(f"{len(delta.changed)} deadline{'s' if len(delta.changed) != 1 else ''} changed")
    if delta.errors:
        parts.append(f"{len(delta.errors)} journal error{'s' if len(delta.errors) != 1 else ''}")
    subject = "cfp-watch: " + "; ".join(parts) if parts else "cfp-watch: weekly digest"

    soon_cut = meta.today + dt.timedelta(days=SOON_DAYS)
    soon = [c for c in store.open_calls(meta.today)
            if (d := parse_date(c.deadline)) is not None and meta.today <= d <= soon_cut]

    body = [f"<p>Run of {escape(meta.today.isoformat())}. <a href=\"{escape(meta.dashboard_url, quote=True)}\">Open the dashboard</a>.</p>"]
    if delta.new:
        body.append("<h3>New calls</h3>" + _email_list(delta.new, meta))
    if delta.changed:
        old = {c.id: prev for c, prev in delta.changed}
        body.append("<h3>Changed deadlines</h3>" + _email_list(
            [c for c, _ in delta.changed], meta, extra=lambda c: f"(was {escape(old[c.id] or '—')})"))
    if soon:
        body.append(f"<h3>Deadlines within {SOON_DAYS} days</h3>" + _email_list(soon, meta))
    if delta.errors:
        items = "".join(f"<li><b>{escape(_jname(meta, k))}</b>: {escape(v)}</li>" for k, v in delta.errors.items())
        body.append(f"<h3>Journals not verified this run</h3><ul>{items}</ul>")
    html = f'<div style="font:15px/1.45 system-ui,sans-serif;max-width:720px">{"".join(body)}</div>'
    return subject, html
```

```python
from __future__ import annotations

import re
import smtplib
from email.message import EmailMessage

SMTP_HOST = "smtp.gmail.com"
SMTP_PORT = 465


def _plain(html: str) -> str:
    text = re.sub(r"<br\s*/?>|</li>|</p>|</h\d>", "\n", html)
    text = re.sub(r"<[^>]+>", "", text)
    return re.sub(r"\n{3,}", "\n\n", text).strip()


def send_email(subject: str, html: str, user: str, password: str, to: str | None = None) -> None:
    msg = EmailMessage()
    msg["Subject"] = subject
    msg["From"] = user
    msg["To"] = to or user
    msg.set_content(_plain(html))
    msg.add_alternative(html, subtype="html")
    with smtplib.SMTP_SSL(SMTP_HOST, SMTP_PORT, timeout=30) as s:
        s.login(user, password)
        s.send_message(msg)
```

```python
from __future__ import annotations

import argparse
import datetime as dt
import os
import sys
from dataclasses import dataclass
from pathlib import Path

import anthropic

from .config import load_journals
from .fetch import fetch_text
from .models import Delta
from .notify import send_email
from .render import RunMeta, render_dashboard, render_email
from .search import DEFAULT_MODEL, find_calls
from .store import Store, merge, record_error

DEFAULT_DASHBOARD_URL = "https://saesoda.github.io/cfp-watch/"


@dataclass
class RunOptions:
    journals: list[str] | None = None
    dry_run: bool = False
    no_email: bool = False
    force_email: bool = False
    model: str = DEFAULT_MODEL
    max_searches: int = 5


@dataclass
class Paths:
    root: Path

    @property
    def config(self) -> Path:
        return self.root / "config" / "journals.yaml"

    @property
    def store(self) -> Path:
        return self.root / "data" / "calls.json"

    @property
    def dashboard(self) -> Path:
        return self.root / "docs" / "index.html"


def run_once(
    opts: RunOptions,
    paths: Paths,
    client,
    today: dt.date,
    sender=send_email,
    fetcher=fetch_text,
    searcher=find_calls,
    env=os.environ,
) -> Delta:
    journals = load_journals(paths.config)
    if opts.journals:
        wanted = set(opts.journals)
        journals = [j for j in journals if j.key in wanted]
    store = Store.load(paths.store)
    total = Delta(new=[], changed=[], expired=[], errors={})

    for j in journals:
        evidence = [t for t in (fetcher(u) for u in j.direct_urls) if t]
        print(f"[{j.key}] searching (evidence pages: {len(evidence)})", flush=True)
        res = searcher(client, j, today, evidence, opts.model, opts.max_searches)
        if res.error:
            print(f"[{j.key}] ERROR {res.error}", flush=True)
            record_error(store, j.key, res.error, today)
            total.errors[j.key] = res.error
            continue
        d = merge(store, j.key, res.calls, today)
        print(f"[{j.key}] found {len(res.calls)}: new {len(d.new)}, changed {len(d.changed)}, "
              f"expired {len(d.expired)}; tokens {res.input_tokens}/{res.output_tokens}", flush=True)
        if res.notes:
            print(f"[{j.key}] notes: {res.notes}", flush=True)
        total.new += d.new
        total.changed += d.changed
        total.expired += d.expired

    meta = RunMeta(today=today, model=opts.model,
                   dashboard_url=env.get("CFPWATCH_DASHBOARD_URL", DEFAULT_DASHBOARD_URL),
                   journals=load_journals(paths.config))
    subject, html = render_email(store, total, meta)

    if opts.dry_run:
        print(f"[dry-run] would write {paths.store} and {paths.dashboard}; email subject: {subject}")
        return total

    store.save(paths.store)
    paths.dashboard.parent.mkdir(parents=True, exist_ok=True)
    paths.dashboard.write_text(render_dashboard(store, total, meta), encoding="utf-8")

    if opts.no_email or not (total.should_email or opts.force_email):
        print(f"no email ({subject})")
        return total
    user, pw = env.get("GMAIL_USER"), env.get("GMAIL_APP_PASSWORD")
    if not user or not pw:
        print("email skipped: GMAIL_USER / GMAIL_APP_PASSWORD not set")
        return total
    sender(subject, html, user, pw, env.get("DIGEST_TO") or None)
    print(f"email sent: {subject}")
    return total


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(prog="cfpwatch")
    sub = ap.add_subparsers(dest="cmd", required=True)
    run = sub.add_parser("run", help="search all journals, update store, dashboard, and email")
    run.add_argument("--journals", help="comma-separated journal keys, e.g. os,smj")
    run.add_argument("--dry-run", action="store_true")
    run.add_argument("--no-email", action="store_true")
    run.add_argument("--force-email", action="store_true")
    run.add_argument("--max-searches", type=int, default=5)
    sub.add_parser("render", help="rebuild the dashboard from the store without searching")
    args = ap.parse_args(argv)

    paths = Paths(root=Path(__file__).resolve().parents[2])
    today = dt.date.today()
    model = os.environ.get("CFPWATCH_MODEL") or DEFAULT_MODEL  # empty env var means default

    if args.cmd == "render":
        store = Store.load(paths.store)
        meta = RunMeta(today=today, model=model,
                       dashboard_url=os.environ.get("CFPWATCH_DASHBOARD_URL", DEFAULT_DASHBOARD_URL),
                       journals=load_journals(paths.config))
        paths.dashboard.write_text(render_dashboard(store, Delta([], [], [], {}), meta), encoding="utf-8")
        print(f"wrote {paths.dashboard}")
        return 0

    opts = RunOptions(
        journals=args.journals.split(",") if args.journals else None,
        dry_run=args.dry_run, no_email=args.no_email, force_email=args.force_email,
        model=model, max_searches=args.max_searches,
    )
    run_once(opts, paths, client=anthropic.Anthropic(), today=today)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

`.github/workflows/weekly.yml`:

```yaml
name: weekly cfp watch

on:
  schedule:
    - cron: "0 0 * * 1"   # Monday 00:00 UTC = 08:00 Hong Kong
  workflow_dispatch:
    inputs:
      journals:
        description: "comma-separated journal keys (blank = all)"
        required: false
        default: ""
      force_email:
        description: "send the digest even if nothing changed"
        type: boolean
        default: false

permissions:
  contents: write

concurrency:
  group: cfp-watch
  cancel-in-progress: false

jobs:
  run:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: pip
      - run: pip install -e .
      - name: run cfp-watch
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GMAIL_USER: ${{ secrets.GMAIL_USER }}
          GMAIL_APP_PASSWORD: ${{ secrets.GMAIL_APP_PASSWORD }}
          DIGEST_TO: ${{ secrets.DIGEST_TO }}
          CFPWATCH_MODEL: ${{ vars.CFPWATCH_MODEL }}
        run: |
          ARGS=""
          if [ -n "${{ inputs.journals }}" ]; then ARGS="$ARGS --journals ${{ inputs.journals }}"; fi
          if [ "${{ inputs.force_email }}" = "true" ]; then ARGS="$ARGS --force-email"; fi
          python -m cfpwatch run $ARGS
      - name: commit results
        run: |
          git config user.name "cfp-watch bot"
          git config user.email "actions@users.noreply.github.com"
          git add data/calls.json docs/index.html
          git diff --cached --quiet && echo "no changes" && exit 0
          git commit -m "cfp-watch: run $(date -u +%F)"
          git push
```

# cfp-watch

Weekly monitor for special-issue calls for papers in 12 management journals
(ASQ, SMJ, SEJ, Organization Science, AMJ, Management Science, JOM, JMS,
Strategy Science, Organization Studies, JIBS, Research Policy).

Dashboard: https://saesoda.github.io/cfp-watch/

## How it works

Every Monday a GitHub Actions job asks Claude (with web search) for each
journal's open special-issue calls, merges them into `data/calls.json`,
rebuilds `docs/index.html`, and emails a digest when there are new calls,
changed deadlines, or a journal that could not be checked.

## Setup (once)

1. Repo secrets (Settings → Secrets and variables → Actions → New repository secret):
   - `ANTHROPIC_API_KEY` — from https://console.anthropic.com/settings/keys
   - `GMAIL_USER` — the Gmail address that sends and receives the digest
   - `GMAIL_APP_PASSWORD` — https://myaccount.google.com/apppasswords (needs 2-step verification on)
   - `DIGEST_TO` — optional; another recipient address
2. Optional repo variable `CFPWATCH_MODEL` (default `claude-sonnet-5`; e.g. `claude-opus-5`).
3. GitHub Pages: Settings → Pages → Source "Deploy from a branch", branch `main`, folder `/docs`.
4. Run it once by hand: Actions → "weekly cfp watch" → Run workflow (tick "force_email" to test the mail).
